# 对 agent 的请求示例

先装载完整 build-project-training Skill，再提供本次语言、学习背景和保存位置。以下是使用请求，不是已生成的题目或已完成的调研。

## 第一套训练

> 我已完成 CS50P 的基础内容。请使用这个 Skill 制作一套 15 题的 Python 项目开发训练，5 道基础、10 道进阶；面向 Windows 11 + WSL，优先免费和低依赖环境。先广泛查阅已有及网上真实项目，按原九维标准筛选来源。题目包含验收标准和分层提示，全部参考代码集中在文末，并交付源码与评分工具。

## 扩展下一套的广度

> 读取之前的题目历史和学习反馈，继续制作下一套 Python 训练，基础与进阶比例 2:3。增加领域、成果形式和工程方法的广度。先说明与最相似旧题的实质差异，按既定调研和准入规则完成，不能只替换故事或数据集。

## 换一种语言

> 使用 C++17 制作一套 15 题训练，3 道基础、12 道进阶。按 C++ 的原生项目调研、内存与资源管理、构建和测试方式安排训练，记录实际编译器与平台。继续使用原有九维权重、来源门槛和去重原则。

## 多语言协作

> 设计 Python 与 JavaScript 协作的训练，覆盖接口合同、失败处理和集成测试；请先根据我的基础建议本套合理的协作题数量。对实际采用的每种语言与整体协作分别取得运行证据，再交付实现。

## 作业批改

> 下面是第 X 题的完整要求、运行环境和全部自写源码。请按九维标准给总评，同时逐行给 0—10 分，解释作用、对错、得分理由和修改建议。保留原文件与行号，区分实际测试和静态推理，给出最高优先级的 1—3 项行动。证据不足请标待验证。

## 修订后复评

> 这是同一道题的第二次提交。请保留前一次记录，用同一验收合同先检查原问题是否解决，再检查新问题。满足可比条件后说明进步与仍需练习的地方，并继续逐行批改。
