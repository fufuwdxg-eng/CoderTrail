# 验证范围与复现入口

本文件描述评分工具自身的验证边界，不是网上项目的质量评分。验证样本不得加入题库，也不计作交付的训练题。

- 环境已实际运行 Python、Node.js JavaScript、g++ C++17，以及 Python 调用 JavaScript 的协作流程。
- 准入逻辑检查包括原权重/85 分边界、严重单项缺失、临界分复核、源码与执行证据绑定、跨语言去重、新组合审阅和难度画像。
- 执行检查覆盖真实输入输出、失败反馈、超时、工具缺失、零/跳过用例、JUnit 计数、旧结果清理、XML 限制、日志/源码变化、失败历史保留和源码打包。
- 作业批改检查覆盖逐行原文与证据绑定、完整覆盖、共享根因、不确定判断、九维加权总评及低分学习记录。
- 当前未安装 Go、Rust、Java、.NET 或 TypeScript 编译器；它们保留适配规则，不能声称本环境已经实际验证这些语言。桌面浏览器、移动设备和硬件任务需要另外的运行环境。
- 自动测试不证明九维审阅客观正确、不证明任意源码可信，也不替代真实网上来源深审或学习效果验证。合格来源库仍需在实际出题任务中积累。

复现命令（在技能目录内或替换绝对路径）：

```bash

python3 -B scripts/test_project_grader.py

```

项目级试运行使用 assets/validation-fixtures 下对应清单，按 scoring-program.md 的 run → verify → grade → package 流程执行。真实执行档案在当次工作目录生成；不要把测试脚本中的合成评分记录当成实际项目认证。

## 跨语言验证样本的输入合同

样本只用于核验运行器：输入为最多 10000 个 ASCII 十进制整数，允许单个前导正负号及任意个前导零，数值范围 [-1000, 1000]。分隔符只允许 ASCII 空格、制表、回车、换行、垂直制表和换页；非 ASCII 空白或数字均无效。空输入输出 0。合法输入输出总和加换行；无效输入 stdout 为空、stderr 为 `INVALID` 加换行、退出码为 2。实际项目必须另写自己的验收合同。

每种语言的清单含 12 个用例；协作清单含 36 个用例。补入特殊空白和长前导零后，应分别重跑原生版本与协作调用，不能仅根据翻译相似度判定等价。
